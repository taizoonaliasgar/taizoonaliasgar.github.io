## 🧠 Projects

### Lead author

- **[Multi-Rate NMPC for Wall-Supported Bipedal Locomotion](bipedal-mr-nmpc5.md)** · IEEE/RSJ IROS 2026  
  A multi-rate NMPC that jointly plans footsteps and body motion, achieving **2.9× higher success** than a Raibert-heuristic baseline over 250 randomized rough-terrain trials (simulation), with preliminary hardware deployment on a Unitree Go2.  
  [Project page](bipedal-mr-nmpc5.md) · [Paper (arXiv)](https://arxiv.org/abs/2607.01574) · [Video](https://www.youtube.com/watch?v=N6XwNJ0E9s0)

- **[Robust MPC for a Tremor-Suppression Exoskeleton](rmpc-exoskeleton.md)** · ASME JDSMC (accepted)  
  A robust MPC with state-dependent cost weighting that cuts tracking error by **up to 47%** versus observer-based MPC on patient-derived tremor (simulation).  
  [Project page](rmpc-exoskeleton.md) · [Video](https://www.youtube.com/watch?v=X2gqHbkB6GM)

### Co-author

- **Decomposition-Based NMPC for Quadrupedal Loco-Manipulation** · IEEE RA-L 2026  
  Implemented the real-time interface between a 60 Hz decomposition NMPC planner and a 500 Hz QP-based whole-body controller; supported hardware validation on a Unitree Go2 carrying a 4.4 kg Kinova arm.  
  [Video](https://www.youtube.com/watch?v=SaZMqanFWv0)

- **Safety-Critical Distributed NMPC for Multi-Robot Quadrupedal Teams** · IEEE RA-L 2025  
  Co-developed a 100 Hz distributed nonlinear MPC for Unitree A1 robot teams; fixed real-time data-pipeline and communication-delay issues to enable stable hardware experiments.  
  [Video](https://www.youtube.com/watch?v=N0z3zvkmvW4)
